# IMDB Sentiment Classification, Summarization & Experiment Tracking

This project implements a comprehensive Natural Language Processing (NLP) pipeline that covers **Sentiment Analysis**, **Text Summarization**, and **MLOps Experiment Tracking**. It compares traditional Machine Learning approaches (TF-IDF + Classifiers) against state-of-the-art Pre-trained Transformer models from HuggingFace, logging all variations using MLflow.

## 📊 Dataset
The project uses the popular **[IMDB Dataset of 50K Movie Reviews](https://kaggle.com)** from Kaggle, containing 50,000 highly polar movie reviews for binary sentiment analysis.

---

## 🚀 Key Features & Pipeline

1. **Data Preprocessing & Cleaning:**
   * Text lowercasing, HTML tag (`<br />`) removal, and non-alphabetic noise cleaning using regex.
2. **Feature Extraction:**
   * Text vectorization using `TfidfVectorizer` (with dynamically tuned max features).
3. **Baseline & Machine Learning Models:**
   * **Naive Bayes** (MultinomialNB)
   * **Logistic Regression** (optimized with hyperparameter tuning)
4. **HuggingFace Integration:**
   * Evaluation of a pre-trained **Sentiment Analysis Pipeline** for zero-shot testing.
   * Abstractive text summarization using the pre-trained **BART model** (`facebook/bart-large-cnn`).
5. **MLOps Tracking with MLflow:**
   * Experiment logging with parameters, metrics (Accuracy & F1 Score), and model artifacts.
   * Serving the MLflow UI securely in a cloud/Colab environment using `ngrok`.

---

## 💡 Key Findings

* **Custom vs. Pre-trained:** A domain-specific **TF-IDF + Logistic Regression** model trained directly on the IMDB dataset (91.0% accuracy on a sample benchmark) **outperformed** a general-purpose pre-trained HuggingFace transformer model (84.5% accuracy), while being dramatically faster during inference.
* **Classifier Performance:** Logistic Regression consistently outperformed Naive Bayes when using the same TF-IDF features.
* **Summarization:** The quality of BART summarization depends heavily on the configuration parameters (`max_length` & `min_length`). Setting a short token limit can sometimes truncate outputs mid-sentence due to token-boundary cutoffs.

* **Language:** Python

## 💻 Getting Started & Usage

### 1. Prerequisites & Installation
Install the necessary python packages:
```bash
pip install "transformers==4.46.3" "tokenizers>=0.20,<0.21" kagglehub mlflow==2.19.0 pyngrok pyarrow -q
```

### 2. Dataset Setup
The notebook uses `kagglehub` to download the IMDB dataset automatically. Make sure you have your Kaggle credentials configured if required, or update the dataset path locally.

### 3. Hyperparameter Tuning Experiments
The pipeline automatically runs multiple training cycles to find the best configuration using the following grids:
* `max_features`: [3000, 5000, 8000]
* Regularization `C`: [0.5, 1.0, 5.0]

### 4. Running the MLflow Tracking UI
To launch the tracking server with an SQLite backend and expose it via ngrok tunnel (specifically for Google Colab environments):

```python
# Run MLflow server in the background
mlflow server --backend-store-uri sqlite:///mlflow.db --host 0.0.0.0 --port 5000
```
Then, connect your Ngrok Auth Token to access the public link generated by `pyngrok`.
